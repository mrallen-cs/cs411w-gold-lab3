# The "Delete Task" Option
The text below is from Lab 2 Section 3 as a placeholder. For Lab 4, we must express these requirements in a more "User Manual"-like wording.

The Scheduler is prompted if they are sure they wish to remove the task. When confirmation is provided, the task is removed from the Calendar View and the Gold Star database.

The system shall ensure a specified task is removed from the following after the Scheduler’s approval:
- The Scheduler’s Calendar View
- The Gold Star database
