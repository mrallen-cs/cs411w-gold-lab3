# The "Previous Month" Option
The text below is from Lab 2 Section 3 as a placeholder. For Lab 4, we must express these requirements in a more "User Manual"-like wording.

The Calendar View page displays the previous month's Calendar View in a monthly calendar format.
The application shall provide the capability to display the Monthly Calendar View for the preceding month's days.
The application shall display the preceding year's December's Monthly Calendar View if a December Monthly Calendar View is displayed.

# The "Next Month" Option
The text below is from Lab 2 Section 3 as a placeholder. For Lab 4, we must express these requirements in a more "User Manual"-like wording.

The Calendar View page displays the next month's Calendar View in a monthly calendar format.
The application shall provide the capability to display the Monthly Calendar View for the succeeding month's days.
The application shall display the succeeding year's January's Monthly Calendar View if a January Monthly Calendar View is displayed.
