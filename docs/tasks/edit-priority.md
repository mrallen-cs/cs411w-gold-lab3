# Editing Priority Levels
The text below is from Lab 2 Section 3 as a placeholder. For Lab 4, we must express these requirements in a more "User Manual"-like wording.

The system prompts the Scheduler to specify priority levels for the given task using a Task Management form.
The current priority level choice is displayed on the Task Management form.
The task and its corresponding priority level are validated. The task and priority level are then saved to the Gold Star database.

The system shall provide the capability to classify tasks in the following Priority Levels:
- Low
- Medium
- High
