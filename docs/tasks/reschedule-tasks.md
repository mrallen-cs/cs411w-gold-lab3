3.1.5.2. Stimulus/Response Sequences
Stimulus: The Scheduler selects an unfinished task to reschedule.
Response: The system allows the Scheduler to move the unfinished task to another day.
Stimulus: The Scheduler selects a new date for the unfinished task.
Response: The system updates the task's scheduled date to reflect the Scheduler's selection.
