# Selecting a Mood
The text below is from Lab 2 Section 3 as a placeholder. For Lab 4, we must express these details in a more "User Manual"-like wording.

3.1.4.1. Introduction/Purpose
Daily Mood Check-In allows Schedulers to record their current mood when using Gold Star.
This feature helps Schedulers reflect on their emotional state while managing daily tasks.
Schedulers can select a mood which best represents how they are feeling.

3.1.4.2. Stimulus/Response Sequence
Stimulus: The Scheduler selects a mood for daily check-in.
Response: Gold Star saves the selected mood for the Scheduler's daily check-in.

3.1.4.3.1. Daily Mood Check-In (O: Nebuchadnezzar)
The system shall allow the Scheduler to specify a mood for their daily check-in.

3.1.4.3.2. Store Daily Mood Check-In (O: Nebuchadnezzar)
The system shall save the mood specified by the Scheduler for their daily check-in.

3.1.4.3.3. Edit Daily Mood Check-In (O: Nebuchadnezzar)
The system shall allow the Scheduler to edit their mood throughout the day.
